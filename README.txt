こもれび手帳 v2

内容:
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面追加用の設定
- sw.js: オフライン起動用キャッシュ
- icon-192.png / icon-512.png: アプリアイコン

公開方法:
1. このフォルダの中身を、HTTPS対応の静的ホスティング先へアップロードします。
2. 公開された https:// のURLをAndroid Chromeで開きます。
3. Chromeメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。

データ:
- IndexedDBに自動保存します。
- 機種変更前に「JSONバックアップ」を実行します。
- 新端末で同じHTTPSアプリを開き、「バックアップを復元」からJSONを読み込みます。
- 旧版のCSVも「旧版CSVを読み込む」から取り込めます。

注意:
- HTTPS公開は利用者側で必要です。このZIP自体を開くだけではPWAとして完全動作しません。
- IndexedDBはブラウザ内保存です。クラウド同期ではありません。
- ブラウザデータ削除・端末故障に備え、JSONバックアップをGoogle Drive等にも保管してください。
- 旧版のデータを引き継ぐ場合は、旧版を開けるうちにCSVを書き出しておいてください。
